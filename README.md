# 🏨 Hotel Management System (ASP.NET + MySQL + Docker)

This repository contains a **Hotel Management Web Application** developed using the **ASP.NET framework**, integrated with a **MySQL** database and containerized using **Docker**. 
This project was created as a collaborative effort for our *Database Management Systems* class.

## 📌 Project Overview

The Hotel Management System is a full-stack web application that allows hotel staff to manage reservations, customers, rooms, and check-in/check-out operations efficiently. 

It demonstrates the integration of:

- ASP.NET for building the backend and frontend logic.
- MySQL as the relational database to store hotel records.
- Docker for containerization and simplified deployment.
- Visual Studio and Visual Studio Code for development and testing.
